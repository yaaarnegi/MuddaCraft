# Genjutsu Creative Direction & Finishing Polish

## 1. The Anti-AI-Slop Manifesto
* **No Generic Blue/Purple Gradients:** Eliminate clichéd generic tech templates and cookie-cutter startup aesthetics.
* **Grounding in Physical Craft:** Root every visual element in tangible textures, authentic history, and distinct personality (e.g. natural reed grain, organic cord knots, sun-cured patinas).
* **The Interaction Thesis:** Before building UI or motion, define the *thesis*:
  * *Tone:* Earthy, contemplative, timeless, premium.
  * *Signature Moment:* Rotating 3D handcrafted mudda with frosted liquid-glass panels reflecting warm ambient lighting.

## 2. Micro-Polish Standards
* **Specular Borders:** Hairline borders with light refraction angles.
* **Liquid Glass Panels:** Apple-inspired frosted glass panels that warp and refract underlying content with high-fidelity blur.
* **Magnetic Touchpoints:** UI elements gently acknowledge the user's cursor before click.
* **Haptic & Sound Visuals:** Visual feedback (subtle scale dip, particle drift, ripple release) that substitutes for physical touch.
