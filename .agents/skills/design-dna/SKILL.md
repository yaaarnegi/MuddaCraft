# Design DNA Framework

## 1. The 5 Pillars of Design DNA
Every cohesive visual interface must be defined by 5 synchronized layers:

1. **Color Chemistry:**
   * Primary brand anchor (e.g. Terracotta `#b85028`)
   * Environmental neutrals (warm stone, cane beige `#f3ede2`, soft cream `#faf8f5`)
   * Accent pops (brass gold `#d4a373`, deep moss `#2d4a34`)
   * High contrast text (`#1f1e1c` on light, `#faf8f5` on dark).
2. **Typographic Rhythm:**
   * Editorial pairing: A characterful serif for titles (`Playfair Display`, `Georgia`) combined with a functional modern sans-serif for UI (`Inter`, `system-ui`).
   * Hierarchy: `h1` (3rem+), `h2` (2.2rem), `h3` (1.3rem), body (1rem / 1.6 line-height), captions (0.8rem / 0.05em tracking).
3. **Spatial Cadence:**
   * Strict adherence to 4px/8px multiples (8px, 16px, 24px, 32px, 48px, 64px, 96px).
   * Generous white-space breathing room to convey luxury and craftsmanship.
4. **Materiality & Surfaces:**
   * Multi-layered depth: Glassmorphism blur, subtle hairline borders (`rgba(0,0,0,0.06)`), specular rim reflections.
   * Tactile organic textures (cane weaves, paper grain, brushed brass).
5. **Motion Signature:**
   * Unified duration and easing curves across all UI components so micro-interactions feel like they belong to the same physical world.
